Dependencies#

ShapePipe’s dependencies are installed automatically — the recommended path is the container, which bundles all of them (see also Installation). pyproject.toml is the authoritative list: it declares the abstract minimum versions ShapePipe is compatible with, while uv.lock pins the exact versions that ship in a given build. The tables below describe the main packages; for the complete, current set always refer to pyproject.toml.
